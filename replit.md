# Running on Replit

This project is a React, Vite, and TypeScript portfolio.

- Run the app with the **Start application** workflow.
- The development server listens on `0.0.0.0:5000` so it works in Replit Preview.
- Run checks with `npm run lint`, `npm run typecheck`, and `npm run build`.

Public contact details, a resume link/file, final dates, and approved project imagery remain optional launch inputs documented in `README.md`.
